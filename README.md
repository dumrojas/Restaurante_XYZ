# Restaurante XYZ

Sistema web para la gestión de reservas de mesas y pedidos de un restaurante.

## Estructura del repositorio

- `frontend/` : interfaz de usuario (HTML5, CSS3 y JavaScript Vanilla).
- `backend/` : microservicios en PHP 8 con Slim Framework y Eloquent ORM (pendiente).

## Ramas

Todo el desarrollo se maneja sobre la rama `main`.
